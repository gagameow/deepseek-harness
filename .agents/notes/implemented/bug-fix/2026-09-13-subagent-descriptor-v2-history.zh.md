# Agent Note：已发布子代理描述符 v2 历史

Status: implemented

[English](2026-09-13-subagent-descriptor-v2-history.md) | 中文

## 问题

已发布的子会话日志可能包含版本 2 描述符，而会话格式迁移按版本 3 校验描述符。拒绝该记录会阻止历史恢复；只放行迁移则仍无法在冷续聊时识别子代理。

## 决策

历史载荷校验器接受精确的版本 2 结构，该结构没有版本 3 的可选推理强度字段。子代理描述符折叠器校验相同结构，并在内存中返回独立的当前描述符。迁移保留存储载荷，不添加推理强度。

## 考虑过的替代方案

重写存储版本号会无必要地修改用户历史。接受任意描述符版本会掩盖未经审查的配置差异。只放宽迁移校验会使冷续聊继续失败。

## 后果

已发布历史无需存储迁移即可读取并继续对话。格式错误的版本 2 记录和不支持的未来版本仍保持已有的拒绝或无法分类行为。
